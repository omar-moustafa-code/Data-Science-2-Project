# Fundamentals of Data Science 2 Project

## Overview
This project investigates the relationships between key health indicators—blood pressure, BMI (Body Mass Index), and life expectancy. The primary goal was to analyze and visualize how these variables correlate with each other and with overall health outcomes. This was completed as the term project for a fundamentals of data science course, using Python for all analysis.

## Repository Contents
*   **`DSCI 1412 Project.ipynb`**: The Jupyter Notebook containing the complete analysis code, visualizations, and commentary.
*   **`DSCI 1412 Project Report.pdf`**: The final project report detailing the methodology, findings, and conclusions.
*   **`DSCI 1412 Presentation.pdf`**: The slide deck for the project presentation.
*   **`life_expectancy_file.csv`**: The dataset used for the analysis.

## Key Questions Explored
*   What is the nature of the relationship between blood pressure and life expectancy?
*   How does BMI correlate with life expectancy?
*   Are there observable relationships between blood pressure and BMI?
*   Can these health indicators be used to predict or understand variations in life expectancy?

## Tools and Techniques
*   **Python**: The primary programming language for data analysis.
    *   `Pandas`: For data loading, cleaning, transformation, and manipulation.
    *   `Matplotlib`: For creating static, foundational visualizations like scatter plots, line graphs, and histograms.
*   **Analysis**: Exploring relationships and correlations between key variables using statistical and graphical methods.

## How to Reproduce This Work
1.  Clone this repository to your local machine.
2.  Ensure you have Python and Jupyter Notebook installed.
3.  Install required libraries: `pandas` and `matplotlib`.
4.  Open and run the `DSCI 1412 Project.ipynb` notebook to reproduce the analysis and visualizations.
